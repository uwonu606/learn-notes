# learn-notes

[learn 스킬](https://github.com/uwonu606/claude-skills/tree/main/skills/learn)이 쓰는 학습 지도 저장소다. 주제 하나가 디렉토리 하나다.

```
<slug>/
  map.md        지도와 다음 세션 인계
  sessions/     세션 하나에 파일 하나
  sources/      스크립트가 받은 원문 (영상 전사는 올리지 않는다)
  lab/          실험 코드와 출력
```

`LEARN_HOME` 이 이 디렉토리를 가리킨다.
